# FIT3184

Cloud Computing, first offering in 2026 S2. Chief Examiner and Lecturer: Dr Mohammad Goudarzi. Unit Coordinator: Jay Zhao. Head Tutor: TianZhang He.

Assumed background: computer networks (TCP/IP), Linux shell and command line, and a lot of Python. Heavy hands-on component.

## Assessment (no final exam)

| Task | Weight | Due |
|------|--------|-----|
| Quizzes (2 × 15%) | 30% | Weeks 6 and 12 |
| Assignment 1: individual project, containerised web service | 30% | Week 8 |
| Assignment 2: group project, application on AWS or multi-cloud | 40% | Week 14 |

- Quizzes run through the eAssessment team. Missing one loses its 15%.
- GenAI: unrestricted in assignments, banned in quizzes. Competency hurdles apply: an interview/demo checks human understanding, and submitting AI-generated work you can't explain can fail the assignment.

## Weekly rhythm

- 2h interactive lecture + 2h practical lab, plus a minimum 8h self-guided study.
- Review lecture material before class.
- Cloud credit invitations (Google/Oracle/AWS Academy) are once-off with expiry dates. Act on announcements the day they appear.

## Setup

Register a Google Cloud 90-day free trial with a **personal** account before the first applied class. Card verification places a small temporary hold. Already used the free trial in another unit? Register with a different email and card. GCP account issues go to Google Support, not the teaching team.

## Syllabus

1. Basic networking & cloud virtual machines
2. Cloud paradigms & compute (IaaS)
3. Cloud storage architectures & data management
4. Containerization (Docker)
5. Web services, APIs, SOA → microservices
6. Scalability, load balancing, HA, managed Kubernetes
7. Advanced cloud networking & VPCs
8. Serverless & event-driven architecture
9. AI/ML in cloud 1 (AWS SageMaker, NLP, Lex)
10. AI/ML in cloud 2 (MLOps, scaling production AI)
11. Cloud security & identity
12. Industry talk, revision, future trends (DevSecOps on AWS)
