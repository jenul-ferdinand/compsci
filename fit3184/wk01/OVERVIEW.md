# Overview: Cloud Virtual Machines

Week 1 establishes the baseline infrastructure concepts for navigating cloud platforms, framing computer networks as the foundation of distributed systems: IP addressing, subnet masking, route tables, and the core TCP/IP protocol suite, mapped onto virtualised cloud environments.

Key contrasts:

- Local switches and routers versus their software-defined counterparts in the cloud.
- Public subnets (internet-facing resources: web servers, load balancers) versus private subnets (shielding databases and application components).

In the lab: use GCP to inspect default networks and deploy a first Ubuntu VM. Understand default-deny firewall postures, SSH for secure remote administration, and diagnostics with `ping`, `traceroute`, and `tcpdump`.

## Learning objectives

- Explain foundational TCP/IP protocols, Classless Inter-Domain Routing (CIDR) notation, and IP addressing schemes.
