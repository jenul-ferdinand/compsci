# Computer Science Coursework

Coursework from my Computer Science degree at Monash University, one folder per unit.

> Disclaimer: Assignment/exam related content is not for show here; especially in-semester.

- [`fit2102/`](./fit2102): [FIT2102](https://handbook.monash.edu/2026/units/FIT2102?year=2026) (Programming paradigms)
- [`fit2109/`](./fit2109): [FIT2109](https://handbook.monash.edu/2026/units/FIT2109?year=2026) (Software toolkit: shell, Git, containers, debugging)
- [`fit3143/`](./fit3143): [FIT3143](https://handbook.monash.edu/2026/units/FIT3143?year=2026) (Parallel computing)
- [`algorithms/`](https://github.com/jenul-ferdinand/algorithms): submodule containing FIT1008, FIT2004, and FIT3155 (algorithms and data structures units)

More units to come.

## Cloning with submodules

```bash
git clone --recurse-submodules git@github.com:jenul-ferdinand/compsci.git
```
