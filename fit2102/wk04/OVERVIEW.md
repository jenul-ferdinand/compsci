# Overview

This week extends higher-order functions into a tacit or point-free style, where you combine functions declaratively without explicitly connecting inputs and outputs. Observables and RxJS get a deeper treatment, covering more complex applications of pure asynchronous streams. The week then turns to theory with lambda calculus, which should feel familiar: lambda functions and the games you can play with them already appeared in JavaScript.

The tute builds a random number stream, then a jumping dot game where RxJS pipelines handle user input, gravity, randomised jump strength, state updates, and rendering.

## Learning objectives

### Combinators and higher-order functions

- Create new functions from old functions using Combinators
- Create powerful declarative programs using Higher-Order Functions and Combinators

### Functional reactive programming

- Create interactive programs using Observable
