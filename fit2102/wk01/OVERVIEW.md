# Overview

## Learning objectives

### Languages and abstraction

- Explain the difference between syntax and semantics in programming languages
- Explain the need for abstraction from machine instructions to high-level languages

### JavaScript fundamentals

- Create simple programs in JavaScript using mutable and immutable variables, functions, and different looping and conditional constructs
- Explain the relationship between JavaScript functions and objects
- Compare arrow functions and regular function syntax

### Functions and composition

- Contrast composition of programs through higher-order functions versus objects
- Understand that a closure is an anonymous function that captures variables from its enclosing scope
- Understand that higher-order functions receive functions as parameters or return functions
- Understand that the built-in Array methods are higher-order functions which allow for very flexible array operations without hand-coded loops
