# Overview

Lazy evaluation leads to infinite lists, which leads to open-ended sequences, which is the idea behind functional reactive programming. This week explores an FRP library (RxJS) for building elegant, robust interactive web apps. RxJS and Observable are a large part of the assignment.

## Learning objectives

### OOP vs FP

- Compare the goals and abstractions of Object Oriented Programming with Functional Programming
- Explain how ES6 classes can be used to provide a fluent interface and compare this to function chaining

### Closures

- Create programs using closures to achieve: (1) continuations; (2) callback event handling

### Functional Reactive Programming

- Explain the Observable pattern and create asynchronous programs using Functional Reactive Programming
