# Overview

Last week's reduction rules turn into an argument: beta reduction on its own is enough to express any computation. From there the unit leaves JavaScript behind. PureScript shows what the syntax looks like when a language is built for functional programming rather than retrofitted for it, and then Haskell arrives properly, with type inference doing the work TypeScript needed annotations for.

The tute is the first Haskell of the semester: binary trees, n-ary trees, and mapping over `Maybe`, built with recursion, pattern matching, guards, and your own algebraic data types. Two optional exercises on lists and rose trees follow for extra practice. Install the toolchain before class, since the exercises build with `stack`.

## Learning objectives

### Lambda calculus

- Apply reduction steps to lambda calculus expressions and describe how these lead to a general model for computation

### From JavaScript to Haskell

- Describe how Haskell-like languages (and in particular PureScript) improve over JavaScript syntax to better support the functional programming paradigm

### Haskell

- Describe how Haskell uses type inference to perform strong type checking with minimal annotation
- Create small programs in Haskell using:
  - recursion
  - pattern matching
  - guards
  - algebraic data type definitions
