# Workshop 5

The exercises this week are split across two files in the `src` directory: `sequence.ts` and `conslist.js`.

To run the tests, you first need to:

```shell
> npm install
```

then:

```shell
> npm run sequence
```

or:

```shell
> npm run conslist
```

To run all tests for `conslist.ts` and `sequence.ts`:

```shell
> npm run test:run
```

or:

```shell
> npm run test:ui
```
