# Overview

More tricks with higher-order functions, leading to a tacit or point-free style where functions combine declaratively without explicitly connecting inputs and outputs. The week then turns theoretical with lambda calculus, which should feel familiar: lambda functions and the games you can play with them already appeared in JavaScript.

## Learning objectives

### Combinators and higher-order functions

- Create new functions from old functions using Combinators
- Create powerful declarative programs using Higher-Order Functions and Combinators

### Lambda calculus

- Relate the lambda calculus to functional programming
- Apply conversion and reduction rules to simplify lambda expressions
