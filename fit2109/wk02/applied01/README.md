# Week 2 Shell Rescue and Log Automation Starter

This folder is the starter project for the Week 2 applied class.

Start from the folder that contains this file:

```sh
bash check_progress.sh
```

The first score should be below 100%. Follow the applied-class handout, repair the rescue folder, create the required evidence files and scripts, and run the checker again.

Do not edit `check_progress.sh`.

If a later task goes wrong, keep the broken folder and restore from a checkpoint copy instead of starting from zero. From the parent folder:

```sh
mv week2-automation week2-automation-broken
cp -R week2-automation-after-task4 week2-automation
```
