# Week 1 Basic Commands Starter

This folder is the starter project for the Week 1 applied class.

Start from the folder that contains this file:

```sh
./check_progress.sh
```

The first score should be below 100%. Follow the applied-class handout, use basic shell commands to copy and rename files, and run the checker again.

Do not edit `check_progress.sh`. The checker is there so you can see whether your project state is complete.
